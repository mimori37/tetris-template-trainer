テンプレ習得ロードマップ

開幕テンプレを難易度の順に並べた学習ルートです。平らな土台づくりから始めて、Tスピン系、最後にパーフェクトクリアへ進みます。カードのボタンから、そのまま練習に入れます。自己ベスト（一致率）はこの端末に記録されます。

キー設定（キーコンフィグ）

行をクリックすると「キー入力待ち」になります。割り当てたいキーを押してください（Escでキャンセル）。すでに使われているキーを選ぶと、元のアクションと自動で入れ替わります。設定はこの端末に保存され、次回もそのまま使えます。

ゲームパッド（Joy-Con / Proコン）

未接続

Bluetoothで接続した Joy-Con / Nintendo Switch Pro コントローラー等を、ブラウザの Gamepad API で認識します。キーボード・タッチと併用できます。
※ブラウザの仕様上、接続後もパッドのボタンを一度押すまで認識しないことがあります。その場合はどれかボタンを1回押してください。

1Mac / PC の Bluetooth設定で Joy-Con をペアリングする
2このページを開いたまま、パッドのボタンをどれか1回押す（上の表示が「接続中」になればOK）
3下のボタンで持ち方（両手持ち／横持ち）を選ぶ

操作ガイド（キーボード）

仕様：10×20盤面 / 7種1巡 / SRS回転＋壁キック（JLSTZ・I別テーブル）/ ロックディレイ約500ms（移動リセット上限15回）/ Tスピン判定（3コーナー法）/ パーフェクトクリア検出。 テンプレ練習ではライン消去を止めて「形」だけを採点します（1巡目28セルの一致率）。各テンプレは表示された出現順で実際に積み上げ可能な配置から作っています。

テトリス テンプレ積みトレーナー

まずは操作プリセットを選んでください。いつも遊んでいる環境に合わせると、そのままの指の感覚で練習できます。あとから「設定」画面でも変えられます。
