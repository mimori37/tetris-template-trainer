Bluetoothで接続した Joy-Con / Nintendo Switch Pro コントローラー等を、ブラウザの Gamepad API で認識します。キーボード・タッチと併用できます。
※ブラウザの仕様上、接続後もパッドのボタンを一度押すまで認識しないことがあります。その場合はどれかボタンを1回押してください。

キーボード操作（現在の割り当て）

仕様：10×20盤面 / 7種1巡 / SRS回転＋壁キック（JLSTZ・I別テーブル）/ ロックディレイ約500ms（移動リセット上限15回）/ Tスピン判定（3コーナー法）/ パーフェクトクリア検出。 テンプレ練習ではライン消去を止めて「形」だけを採点します（1巡目28セルの一致率）。各テンプレは表示された出現順で実際に積み上げ可能な配置から作っています。
