# テトリス テンプレ積みトレーナー

ガイドライン準拠寄りのテトリス本体に、開幕テンプレ積みのトレーニングとスキルチェックを付けたWebアプリです。
ビルド不要の静的サイトで、GitHub Pages で配信しています。

**公開URL**: https://mimori37.github.io/tetris-template-trainer/

## 動かし方

リポジトリを clone して `index.html` をブラウザで開くだけで動きます（サーバー不要）。

```sh
git clone https://github.com/mimori37/tetris-template-trainer.git
cd tetris-template-trainer
open index.html   # macOS の場合
```

## 画面構成

- **プレイ**: 盤面と最小限の情報だけを表示。モード切替（フリー / テンプレ練習 / スキルチェック）はこの中
- **テンプレ図鑑**: テンプレ習得ロードマップ。STEP順の解説カード、テンプレ別の自己ベスト記録、カードからそのまま練習開始
- **設定**: キーコンフィグ（環境別プリセット / カスタム）、ゲームパッド、操作ガイド
- 起動時はポップアップで操作プリセットと開始モードを選択（「次回から表示しない」も可）
- テーマはライト既定、ダークへの切替あり（端末に保存され、盤面の色も連動）

## 内容

- 本体: 10×20、7種1巡、NEXT5、HOLD、ゴースト、SRS＋壁キック、DAS 130ms / ARR 25ms相当、ロックディレイ500ms、Tスピン判定・コンボ・B2B・パーフェクトクリア検出、180度回転
- テンプレ練習: TKI積み / DT砲 / 開幕PC / 山岳積み / 平積みベース の5種。目標シルエット表示つきで、1巡（28セル）の一致率・PPS・所要時間・置きミスを判定
- スキルチェック: ランダム3題で精度・速度・ミス率・ホールド活用を採点し、S〜Dランクと傾向講評を表示

## 操作

- キーボード: 環境別プリセットを1クリックで切替（標準 / TETR.IO / Jstris / ぷよテト横持ち）。各アクションのカスタム割り当ても可能で、設定はブラウザに保存されます
- コントローラー: Gamepad API で Joy-Con / Pro コンに対応（両手持ち、Joy-Con 1本の横持ちモード）。ブラウザが認識するには、接続後にボタンを一度押す必要があります
- タッチボタン（モバイル）あり

## ディレクトリ構成

| パス | 内容 |
|---|---|
| `index.html` | 画面の骨格 |
| `src/css/style.css` | テーマ変数（ライト / ダーク）と全スタイル |
| `src/js/data.js` | 定数（盤面・色・SRS回転テーブル）と開幕テンプレ定義 |
| `src/js/engine.js` | ゲーム状態・落下 / 回転 / 消去の仕組みと盤面描画、テーマ切替 |
| `src/js/input.js` | キー設定、DAS処理、タッチ、ゲームパッド |
| `src/js/app.js` | 画面遷移・モード・判定・スキルチェック・ロードマップ・起動処理 |
