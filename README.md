# テトリス テンプレ積みトレーナー

ガイドライン準拠寄りのテトリス本体に、開幕テンプレ積みのトレーニングとスキルチェックを付けたWebアプリ。`index.html` / `style.css` / `main.js` の3ファイル構成です。GitHub Pagesでそのまま配信されます。

## 動かし方

フォルダごと配置して `index.html` をブラウザで開くか、GitHub Pages の公開URLからアクセス。

## 内容

- 本体：10×20、7種1巡、NEXT5、HOLD、ゴースト、SRS＋壁キック、DAS 130ms / ARR 25ms、ロックディレイ500ms、Tスピン判定・コンボ・B2B・パーフェクトクリア検出
- テンプレ練習：TKI積み / DT砲 / 開幕PC / 山岳積み / 平積みベース の5種。目標シルエット表示つきで、1巡（28セル）の一致率・PPS・所要時間・置きミスを判定
- スキルチェック：ランダム3題で精度・速度・ミス率・ホールド活用を採点し、S〜Dランクと傾向講評を表示

## 操作

- ←→：移動 / ↓：ソフトドロップ / ↑・X：右回転 / Z：左回転 / Space：ハードドロップ / C：ホールド / P：一時停止 / R：リスタート
- キー設定（標準／ぷよテト横持ち風プリセット＋カスタム）とJoy-Con連携は改修中

## 補足

- キー設定：プリセット（標準／ぷよテト横持ち風）＋カスタム割り当て（ブラウザに保存）
- コントローラー：Gamepad APIでJoy-Con / Proコンに対応（両手持ち・Joy-Con1本の横持ちモード）
- 本作品は非公式の個人作品です。「テトリス」は The Tetris Company の商標です

## 画面構成

- プレイ：盤面と最小限の情報だけ。モード切替（フリー／テンプレ練習／スキルチェック）はこの中
- テンプレ図鑑：テンプレ習得ロードマップ（STEP順の解説カード＋自己ベスト記録＋そのまま練習開始）
- 設定：キーコンフィグ（環境別プリセット／カスタム）、ゲームパッド、操作ガイド
- 起動時はポップアップでプリセットと開始モードを選ぶ（「次回から表示しない」可）
- テーマ：ライト既定、ダーク切替あり（端末に保存、盤面の色も連動）
