# テトリス テンプレ積みトレーナー

ガイドライン準拠寄りのテトリス本体に、開幕テンプレ積みのトレーニングとスキルチェックを付けたWebアプリ。単体 `index.html` で動作します。

## 動かし方

`index.html` をブラウザで開くだけ（サーバー不要）。

## 内容

- 本体：10×20、7種1巡、NEXT5、HOLD、ゴースト、SRS＋壁キック、DAS 130ms / ARR 25ms、ロックディレイ500ms、Tスピン判定・コンボ・B2B・パーフェクトクリア検出
- テンプレ練習：TKI積み / DT砲 / 開幕PC / 山岳積み / 平積みベース の5種。目標シルエット表示つきで、1巡（28セル）の一致率・PPS・所要時間・置きミスを判定
- スキルチェック：ランダム3題で精度・速度・ミス率・ホールド活用を採点し、S〜Dランクと傾向講評を表示

## 操作

- ←→：移動 / ↓：ソフトドロップ / ↑・X：右回転 / Z：左回転 / Space：ハードドロップ / C：ホールド / P：一時停止 / R：リスタート
- キー設定（標準／ぷよテト横持ち風プリセット＋カスタム）とJoy-Con連携は改修中

## 補足

- キー設定：プリセット（標準／ぷよテト横持ち風）＋カスタム割り当て（ブラウザに保存）
- コントローラー：Gamepad APIでJoy-Con / Proコンに対応（両手持ち・Joy-Con1本の横持ちモード）
